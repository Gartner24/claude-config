# 0048. New docs layout (planned destinations for docs-map.md)

Every old fact lands under one of these headings.

## README.md (reader: you, the owner)
- `## What this is`
- `## Where things live` (source of truth table, the claude-home mirror rule, rules for one place only)
- `## One session, start to finish`
- `## Guides`
- `## Rules earned the hard way` (and the ECC language rules on demand)
- `## Stack overview` (languages, runtime, key dependencies, plugins, frameworks, MCP)
- `## Restore on a new machine` (three lines, then SETUP.md)

## AGENTS.md (reader: an AI agent working in this repo; only rules it would not guess)
- `## Commands`
- `## Rules`
- `## Gotchas`
- `## Standing answers`
- `## Agent skills`
- `## Context files`

## docs/architecture.md (reader: /architect and you)
- `## Components`, `## Data flow`, `## Invariants (hold everywhere)`, `## Skills and commands under wf run` (kept)
- `## Specs` (the spec list, moved from AGENTS.md)
- `## Setup sync` (the manifest, patches, /claude-config, spec 0048)

## docs/guides/SETUP.md (Type: how to)
- `## Install on this machine`
- `## Restore on a new machine` (includes hook paths and settings on a new machine)
- `## Frameworks` (gstack, jjstack, get-shit-done pin, ECC, the JSM skills, sentry, anthropic security review)
- `## Downloaded skills` (the manifest, restore, updates through /claude-config, packshot and private copies)
- `## Plugins` (each plugin, its source and install command; the claude-seo marketplace)
- `## MCP servers` (context7, magic, the design MCPs, adding a server)
- `## Keep it current` (update commands for frameworks, plugins, Claude Code)

## docs/guides/DAILY-USE.md (Type: how to)
- `## The workflow chain` (scope, architect, develop, check verify, test, sync; tiers)
- `## Run the runner` (every wf command)
- `## Keep the repo and ~/.claude in sync` (/claude-config, bin/sync.sh before a commit)
- `## Pick a skill` (type the name; routing; the cheat sheet)
- `## Language rules on demand`

## docs/guides/SKILLS.md (Type: reference, generated by `bin/claude-config.py docs`)
- `## Your own skills`, `## Your own commands` (front matter)
- `## Frameworks`, `## Downloaded skills` (manifest: source, status, license, description)
- `## Routing` (copied from `config/routing.md`, the hand written trigger table the intent router reads)

## docs/guides/HOOKS.md (Type: reference)
- `## Where each hook comes from`
- `## Settings the hooks rely on` (autocompact, model, permissions, status line)

## docs/guides/DESIGN-PIPELINE.md (Type: how to)
- `## What runs the pipeline`, `## One time setup`, `## Use it`, `## The two rules that matter most`, `## Reference material`

## Moved whole, content kept
- `docs/guides/USAGE.md` -> `config/routing.md` (every routing block, the format notes, the cheat sheet, reference skills)
- `docs/guides/SKILLS-EVALUATION.md` -> `docs/research/SKILLS-EVALUATION.md`
- `docs/guides/PLUGINS.md` -> `SETUP.md ## Plugins`; `docs/guides/MCP.md` -> `SETUP.md ## MCP servers`

## Dropped on purpose (shown to you before the build ends)
A row may say `dropped: <why>` only for a dated history note whose fact is kept elsewhere (for
example "added 2026-08-06" when the skill itself is listed), or a fact the manifest now records
exactly (a version, an install command, a source URL).
