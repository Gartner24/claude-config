# New number replaces old (spec 0056)

- When the user gives a figure (a price, a count, a rate, a date) that differs from one already written in a skill's own files or the project's docs, replace it there and say "replaced X (date) with Y".
- Never write a figure with no source. Write a bracket placeholder instead, for example `[price: ask the client]`.
- It matters most in customer-research and offers, where an old or invented number turns into a wrong offer.
