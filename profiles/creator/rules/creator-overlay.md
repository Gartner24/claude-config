# Creator overlay (profile creator only; spec 0081 AC-19)

These points beat `CLAUDE.md` and skill text, and only these.

- **Accents and Spanish punctuation.** In text written for people outside the claude-config repo, accented vowels,
  n with a tilde, u with a diaeresis and the inverted question and exclamation marks are allowed, and `/polish` keeps
  them. Code, commands and every file inside the claude-config repo stay ASCII.
- **Quiet start.** `/scope` and `/audit` still start by themselves when a chat opens in a repo, but stay quiet: one
  plain line on where things stand and the next step, no long readout, a question only for a real decision.
- **Free tools only.** Add no paid service or API without the person's yes.
