# How to walk the map

1. Read `CLAUDE.md` at the repo root (always loaded). It holds the rules you must not break.
2. Open [CLAUDE.md](CLAUDE.md) here only to pick a card.
3. Open the object card of the part you change, then [effects/CONTEXT.md](effects/CONTEXT.md) for what else it moves.
4. Open a process card when you run that process.

A rule lives on one card. If a card and the root `CLAUDE.md` disagree, the root file wins; fix the card.

## Names that collide
- workflow: our chain of skills (`/scope`, `/architect`, `/develop`, `/check`, `/test`, `/sync`) versus Claude Code workflows (saved multi-agent scripts, scope rows 100 to 102).
- review: jjstack's `/review` versus Claude Code's built-in reviewer, which is `/code-review`.
- wf: the retired runner ([runner](objects/runner.md)) versus the `wf-handoff` mod ([mods](objects/mods.md)).
- dash: the old `wf-dash` is now `chip-dash` ([mods](objects/mods.md)).
